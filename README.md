# StudyGenie

Turn your courses into a day-by-day study plan.

Add a course with its exam date, break it into topics by difficulty, and
StudyGenie builds a study schedule using urgency scoring and spaced
repetition. Optional Gemini AI features generate practice quizzes.

## Run it

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
